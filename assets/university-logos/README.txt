University logos for the Study Abroad page.

Name each file after the university's slug in the `universities` array in
study-abroad.html, as a PNG with a transparent background:

  assets/university-logos/<slug>.png

  graphic-era-university.png          pp-savani-university.png
  gulzar-group-of-institutes.png      mats-university.png
  sr-university.png                   marwadi-university.png
  desh-bhagat-university.png          lovely-professional-university.png
  royal-global-university.png         sharda-university.png
  amity-university.png                khalsa-university.png
  invertis-university.png             mvm-institute.png
  soa-university.png                  cyprus-west-university.png
  cyprus-international-university.png eastern-mediterranean-university.png
  near-east-university.png            girne-american-university.png

The card falls back to the coloured initials tile whenever a file is absent or
fails to load, so partial coverage is fine.
