TIH Learning Desktop 0.4.2 — sign in first and a continuous lesson page.

The standalone welcome screen uses the same TIH logo and welcome artwork as the APK. Sign in with your existing TIH email and password before entering the desktop library. A saved account opens the library automatically; signing out returns to the welcome screen. Password visibility can be toggled and passwords are cleared after submission.

Videos now appear above their written lessons, matching the APK placement. Players load with autoplay off, and Hide video stops playback. Show video, a YouTube link and an offline retry help learners continue. Videos need internet; YouTube controls playback availability.

Written lessons scroll up and down in the same lesson area as the video. Mouse-wheel and Page Up/Page Down scrolling work over the lesson text. Read the lesson below skips past the video; Top returns to the beginning. Each lesson remembers its reading position across navigation and app restarts. Adjustable text, focus view, notes and course navigation remain available; notes become an overlay on smaller screens.

Computer Literacy and IELTS Masterclass retain their existing lessons, charts, assessments, essay/project studio and independent progress. No additional course is added in this release. Existing version-1 backups remain compatible. Old guest work stays on disk; before upgrading, export a guest backup in the old app, then explicitly restore it into your signed-in account in Settings. Backups from a different student remain rejected.

Approved enrollment is checked separately for each full course. Cached approval lasts up to seven days after verification; Windows secure storage protects saved credentials. Desktop progress and quiz percentages are local study records. Official certificates and course approval remain in TIH Learning Hub.

Validation covers sign-in-first entry, saved sessions, sign-out, reader isolation, video placement/hide/retry, wheel and keyboard scrolling, restored reading positions, layouts at 960 and 1440 pixels, both full courses, assessment grading, essay drafts and separate course permissions. Native Windows checks repeat after installing the generated installer. Account and video tests use controlled responses; real external-service availability is not asserted.

Close the old app, export a workspace backup in Settings, and install in the same location. This Windows x64 preview is unsigned and may show a publisher warning.
