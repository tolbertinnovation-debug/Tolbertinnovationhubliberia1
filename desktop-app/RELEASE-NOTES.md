TIH Learning Desktop 0.3.0 — IELTS Masterclass joins Computer Literacy.

The full IELTS Masterclass: Beginner to Band 9 includes 22 sections, 126 authored lessons, 111 assessments with 376 questions, and a Task 2 essay project. Original reading material, model examples, inline charts, expandable keywords and 127 source-linked companion videos are preserved. Videos need internet.

The IELTS writing studio includes an autosaved essay draft, word count, optional 40-minute practice timer and portfolio file references. The original essay prompt and review rubric remain in the lesson. Record project completion after writing at least 250 words and confirming your review. File references are local; files are not uploaded or reviewed automatically.

Switch between IELTS Masterclass and Computer Literacy in the learning space, overview or progress page. Each course keeps its own bookmark, reading completion, quiz scores, essay/project records and PDF study record. Previous Computer Literacy data stays compatible.

Sign in with your existing TIH account. Approved enrollment is checked separately for each course, with cached offline access for up to seven days after verification. Passwords are not stored; Windows secure storage protects credentials and each student has a separate workspace. Guests can still use the Computer Literacy previews.

Quiz percentages are local learning checks, not official IELTS band scores or test results. Essay/project completion is self-reported. TIH course certification and approval remain in TIH Learning Hub; this app does not issue an official IELTS Test Report Form.

Validation covers full content, chart and keyword rendering, essay drafts, word counts, timed practice controls, grading, independent course progress, restarts, PDF export and separate course permissions on Windows. The checks repeat after installing the generated installer. Account tests use controlled service responses; external YouTube availability is not asserted.

Close the old app, export a workspace backup in Settings, and install in the same location. This Windows x64 preview is unsigned and may show a publisher warning.
