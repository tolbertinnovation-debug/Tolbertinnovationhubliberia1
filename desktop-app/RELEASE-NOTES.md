TIH Learning Desktop 0.1.3 — matching the TIH Learning APK logo.

The desktop sidebar now uses the exact logo image from the Android app. The app window, Windows executable, installer and desktop/Start menu shortcuts use the same artwork converted to Windows icon formats.

The wider learning workspace, reading/video/resources tabs, focus view, full screen, lesson navigation, notes and offline reading remain included. This is a desktop preview with the 57-course catalog and outlines, plus three Computer Literacy lessons. Videos require internet and are subject to YouTube availability. Full courses and assessments will be added course by course.

Close the old desktop app and run the Windows x64 installer to update in the same location. Export a workspace backup from Settings first. The preview is unsigned and may display a Windows publisher warning.
