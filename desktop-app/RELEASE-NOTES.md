TIH Learning Desktop 0.2.0 — Computer Literacy is the first complete desktop course.

The course now includes all 15 modules, 123 authored reading lessons, 125 quizzes/assessments containing 404 questions, and five practical projects from TIH Learning Hub. Existing lesson videos are linked in the video classroom and require internet.

Sign in using your existing TIH account. The full course follows the APK's active-profile and approved-enrollment rules; approved access can be used offline for up to seven days after verification. Guest learners can still try the three previews. Each student's work is stored separately and credentials are protected by Windows secure storage.

New study features include searchable module navigation, quiz drafts and retries, automatic grading and answer explanations, saved best scores, project reflections/file references, course progress and a PDF study record. Project completion is self-reported; files are not uploaded. Official course completion approval and certificates remain in TIH Learning Hub.

The existing larger lesson workspace, focus view, full screen, notes, catalog, focus timer and matching APK logo remain included. Other desktop courses will be added next.

Validation covers content completeness and the learner workflow on Windows, then repeats the checks after installing the generated installer. Account tests use controlled responses rather than a real student login; YouTube availability remains external.

Close the old app, export a backup from Settings, and install in the same location. Previous guest notes remain available; signing in opens that student's separate workspace. This Windows x64 preview is unsigned and may display a publisher warning.
